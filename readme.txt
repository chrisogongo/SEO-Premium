Advanced AI-powered WordPress SEO plugin with content analysis, schema markup, XML sitemaps, redirect management, technical audits, and AI-assisted optimization.

== Description ==

SmartRank AI SEO is a comprehensive SEO management system that helps website owners optimize their entire SEO strategy from the WordPress dashboard.

= Core Features =

* **Professional Dashboard** — SEO health score, traffic metrics, issue tracking
* **On-Page SEO Editor** — Real-time content analysis with Google snippet preview
* **AI SEO Assistant** — Generate meta descriptions, SEO titles, content briefs
* **Schema Markup Generator** — 15+ Schema.org types with JSON-LD output
* **XML Sitemap Management** — Automatic generation for posts, pages, products, categories
* **Redirect Manager** — 301/302/307 redirects with loop detection
* **Technical SEO Audit** — Automated scanning with prioritized issues
* **404 Monitor** — Track and fix broken URLs
* **Local SEO** — Business information management with LocalBusiness schema
* **Keyword Research** — Keyword management and organization
* **WooCommerce SEO** — Product page optimization with Product schema

= AI-Powered Features =

* Generate SEO titles and meta descriptions
* Create content briefs and outlines
* Analyze content for SEO optimization
* Support for OpenAI, Anthropic, and Google AI providers

= Security =

* All inputs sanitized, all outputs escaped
* Prepared database queries
* Nonce verification on all forms
* Capability checks on admin pages
* Secure REST API endpoints
* No WordPress core file modifications

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to SmartRank SEO → Settings to configure
4. (Optional) Add your AI API key for AI features

== Frequently Asked Questions ==

= Do I need an AI API key? =

No. All core SEO features work without AI. The AI assistant is optional.

= What schema types are supported? =

Organization, LocalBusiness, WebSite, WebPage, Article, BlogPosting, Product, Service, BreadcrumbList, Person, Event, VideoObject, FAQPage, and more.

= How do XML sitemaps work? =

Sitemaps are automatically generated at `/sitemap.xml` with sub-sitemaps for posts, pages, categories, and products.
